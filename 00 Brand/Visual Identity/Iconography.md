# Iconography

134 line and glyph icons. Apparel, packaging, shipping states, delivery handling, manufacturing equipment.

## Builds

| Build | Fill | Use | Location |
|---|---|---|---|
| Pink | `#ED128C` | Brand marketing, decks, one pagers | `99 Assets/Brand Kit/Icons/` (in vault) |
| currentColor | inherits text color | Web and app UI, recolor with CSS | Drive kit `04_Icons/SVG_CurrentColor/` |
| Black | `#000000` | Print, labels, documents | Drive kit `04_Icons/SVG_Black/` |

Filenames match across all three builds. Swap folder, keep the name.

## Rules

- 24px box in UI
- Pair with a text label unless the meaning is universal
- Never fill with the gradient
- Never outline
- Never mix with another icon library in one screen
- Inline UI icons (nav, arrows, check circles) are a separate register: Heroicons style stroke, 1.5 to 2px, rounded caps
- Missing glyph: match the thin line style or use a thin stroke Lucide icon and flag it

## Known gap

Set was assembled from several sources. viewBoxes vary across 26, 32, 50 and 64 units. Stroke weights are not uniform. Consistent within a group, not always across groups. Open item: standardize to one 24px grid and one stroke weight.
