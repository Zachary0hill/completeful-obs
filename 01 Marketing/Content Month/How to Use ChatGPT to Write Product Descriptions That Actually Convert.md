**HOOK**
*ChatGPT can write your product descriptions in 30 seconds. But only if you prompt it correctly.*

**KEY POINTS**
1. Prompt formula: "Write a product description for [product] targeting [audience] on [platform]"
2. Include keywords you want ranked for (Etsy SEO terms)
3. Ask for emotional benefits first, features second
4. Request bullet points for easy scanning
5. Always edit the output, add your brand voice and remove generic AI phrasing

(0:00–0:03) HOOK: ChatGPT can write your product descriptions in thirty seconds, but only if you prompt it right.
(0:03–0:15) Dump in "write a description for my mug" and you get bland, generic AI fluff that converts nobody. The trick is the prompt.
(0:15–0:45) Use this formula: "Write a product description for this product, targeting this audience, on this platform." Feed it the exact keywords you want to rank for, your real Etsy SEO terms.
