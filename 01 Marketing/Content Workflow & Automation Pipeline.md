# Content Workflow & Automation Pipeline

## Overview

Completeful's content at scale is produced through a fully automated multi-agent pipeline, built in n8n and orchestrated through Notion. The system is designed to take a content brief from idea to published post — across six channels, at daily volume — without requiring manual production work at each step. Human review happens at defined checkpoints, not throughout.

This pipeline is referred to as the **Content Orchestra**.

---

## The Pipeline in Five Stages

### Stage 1: Brief Creation and Trigger (Notion)

Everything begins in the Notion content database. A content brief is created — either manually by the team or generated by the Strategy agent based on a weekly theme or a detected content gap — and added to the Notion content DB with the following fields:

- Content angle / topic
- Target platform(s)
- Content type (carousel, short video, blog post, etc.)
- Brief ID
- Status: `Brief Ready`

When a card's status is set to `Brief Ready`, Notion fires a webhook to n8n. This is the trigger that starts the pipeline.

### Stage 2: Orchestration (Conductor Agent via n8n)

The Conductor agent receives the webhook payload from Notion and reads the brief. Based on the content type and target platforms, the Conductor determines which downstream agents to invoke and in what sequence. It sets the routing logic for the entire job:

- Long-form brief (blog, YouTube) routes through: Strategy → Long-Form Writer → QC → Formatter → Publisher → Analyst
- Short-form brief (caption, carousel, short video) routes through: Strategy → Hook Generator → Social Writer → QC → Formatter → (Atomizer if multi-platform) → Publisher → Analyst

The Conductor writes an intermediate status back to Notion: `In Generation`.

### Stage 3: Content Generation (AI Agents via GPT-4o)

Agents execute in sequence. Each writes its output back to Notion and passes the result to the next agent in the chain.

**Strategy Agent:** Develops the content angle, key points, platform-specific approach, and any supporting context from Completeful's product catalog or current campaigns.

**Hook Generator:** Writes 3–5 opening hook options optimized for the target platform. Hooks are selected or ranked before the Social Writer proceeds.

**Social Writer:** Writes final short-form captions for each designated platform. Applies brand voice rules: coaching tone, seller-first framing, no emojis, no dashes.

**Long-Form Writer:** Produces full blog posts or YouTube scripts. Structures content for SEO where applicable. Passes output to QC before formatting.

### Stage 4: Quality Control and Human Review

**QC Agent:** Reviews all generated content against brand voice guidelines, factual accuracy (product names, platform integrations, pricing claims), and formatting rules. Flags violations and either auto-corrects minor issues or sends the item back for regeneration. Passes clean items to Notion with status: `QC Passed`.

**Human Review Checkpoint:** A team member reviews QC-passed items in Notion. The Notion card presents the generated content and a simple approve / request revision decision. This is the single mandatory human touch-point before content proceeds to production.

Approved items are marked `Approved`. Revision requests return the card to the relevant agent with notes.

### Stage 5: Formatting, Production, and Publishing

**Formatter Agent:** Takes approved text and invokes the Canva Connect API to generate platform-formatted graphics (carousels, thumbnails, branded statics). Confirms that outputs match brand specs (Pink #ED128C, gradient #FF2B92 to #FF8433, Navy #34424E; Owners or Archivo headlines, Inter body). Spec: [[00 Brand/Visual Identity/_Completeful Brand System|Completeful Brand System]].

For video content, the Formatter works with Remotion templates and ElevenLabs for voiceover. The Formatter outputs finished media files and links them back to the Notion card.

**Atomizer Agent (when applicable):** Repurposes approved long-form content into multiple short-form pieces — a blog post becomes three Instagram carousel concepts and two X posts. This is how Completeful maintains multi-channel volume without proportionally multiplying brief creation work.

**Publisher Agent:** Schedules and pushes approved, formatted content to the correct platforms at the scheduled time. Writes publish confirmation and post IDs back to the Notion card. Status updated to `Published`.

**Analyst Agent:** After a defined window post-publish (typically 24–72 hours), the Analyst pulls performance data for each post and writes a brief summary back to the Notion card (reach, saves, shares, comments, watch time where available). High-performing content flags are surfaced to the Strategy agent to inform future briefs.

## The 10-Agent Content Orchestra

| # | Agent | Stage | Primary Role |
|---|---|---|---|
| 1 | Conductor | Orchestration | Routes briefs, manages handoffs, maintains pipeline state |
| 2 | Strategy | Generation | Develops angles, themes, and platform approach |
| 3 | Hook Generator | Generation | Writes platform-optimized opening hooks |
| 4 | Social Writer | Generation | Writes short-form captions for all social channels |
| 5 | Long-Form Writer | Generation | Writes blog posts and YouTube scripts |
| 6 | QC | Review | Brand voice, accuracy, and formatting compliance check |
| 7 | Formatter | Production | Canva API graphic generation, video/audio assembly |
| 8 | Atomizer | Production | Repurposes long-form content into short-form multi-channel pieces |
| 9 | Publisher | Publishing | Schedules and posts content to each platform |
| 10 | Analyst | Analysis | Pulls post performance data, feeds insights to Strategy |

## Operational Notes

- The pipeline does not run without a brief in Notion. Content generation is not triggered by time — it is triggered by a brief reaching `Brief Ready` status.
- The human review checkpoint after QC is non-negotiable. Nothing is published without approval.
- Brand voice failures flagged by the QC agent are the most common regeneration trigger. If QC rejection rates rise, the upstream agent prompts should be reviewed.
- All pipeline decisions (tool changes, agent additions, workflow restructures) are logged in [[Decision Log]].
