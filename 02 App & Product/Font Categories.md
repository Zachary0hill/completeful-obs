# Font Categories

> Raw note: "Font Categories"

## Problem / Goal
Organize the designer's font library into browsable categories so users can find type styles by use-case instead of scrolling one long list.

## Proposed Approach
- Define a category taxonomy (e.g., Serif, Sans, Script, Display, Handwritten, Monospace).
- Tag every font in the library with one or more categories.
- Add a category filter/chips row to the font picker UI.

## Sub-tasks
- [ ] Decide final category list and tag the font catalog.
- [ ] Build category filter UI in the designer font panel.
- [ ] Add search-within-category.

## Open Questions
- Should categories be curated by us or auto-detected from font metadata?
- Do we need a 'recently used' / 'favorites' category too?
