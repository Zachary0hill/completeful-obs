# Global Function: Edit Generated Design then Regenerate Mocks

> Raw note: "Global function: Ability to edit generated design -> Regenerate mocks"

## Problem / Goal
Provide a global capability to edit a generated design and then regenerate its mockups from the edit.

## Proposed Approach
- Allow editing of a generated design anywhere it appears.
- Trigger mockup regeneration from the edited design.
- Keep versions/links between design and mocks.
