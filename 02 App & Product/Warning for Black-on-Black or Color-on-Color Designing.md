# Warning for Black-on-Black or Color-on-Color Designing

> Raw note: "Add warning for black on black or color on color designing"

## Problem / Goal
Warn users when their design color is too close to the product color (low contrast), which prints poorly.

## Proposed Approach
- Detect low contrast between design elements and product/base color.
- Show a non-blocking warning with guidance.
- Link to color contrast checker and guidelines.

## Sub-tasks
- [ ] Define contrast threshold logic.
- [ ] Add warning UI in the designer.
- [ ] Cross-link to color contrast checker.

## Open Questions
