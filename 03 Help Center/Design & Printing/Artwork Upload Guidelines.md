# Artwork Upload Guidelines

Submitting artwork that meets these guidelines will give you the best possible print result. Poor file quality is the most common reason prints come out blurry, color-shifted, or with unexpected edges. Take a few minutes to check your files before uploading.

## Resolution and DPI

- **Minimum:** 150 DPI at the final print size
- **Recommended:** 300 DPI at the final print size
- **For large-format products** (banners, posters, canvas prints): 150 DPI is acceptable, but 200+ DPI is preferred

If you design at a small canvas size and then scale it up in the product builder, your effective DPI drops. Always design at or above the actual print dimensions.

**Example:** A 12" x 12" print at 300 DPI requires a canvas of at least 3600 x 3600 pixels.

## Color Mode

- **Use RGB color mode** for all digital file uploads. Completeful's production equipment interprets files in RGB.
- If your design was created in CMYK (common in print design software), convert it to RGB before exporting. Colors can shift when switching between modes — review the result before submitting.
- For sublimation products (mugs, totes, puzzles), vivid RGB colors translate especially well because sublimation ink is highly saturated.

## File Format

- **PNG** is strongly recommended, especially for designs with transparency.
- **JPG** is accepted but not recommended for designs with text or sharp edges — JPG compression creates artifacts.
- **SVG and PDF** are accepted for certain products. See **Supported File Formats** for details.
- Maximum file size: 50 MB per upload.

## Transparent Backgrounds

- Use PNG with a transparent background for any design that should be placed directly on the product color without a white box behind it.
- Do not use a white background unless you specifically want a white rectangle printed on the product.
- Check your file in an image viewer that shows transparency (the checkerboard pattern) before uploading.

## Bleed and Safe Area

- **Bleed:** Extend background elements and edge-to-edge designs 0.125 inches (3mm) beyond the print boundary to avoid white slivers caused by slight misalignment during cutting.
- **Safe area:** Keep all critical elements — text, logos, faces — at least 0.25 inches (6mm) inside the print boundary so nothing important is cut off.
- The product builder shows bleed and safe area guides. Use them as a final check before saving.

## Text in Artwork

- Convert all text to outlines or paths before exporting, especially if using custom or purchased fonts. This prevents font substitution.
- Minimum recommended font size for legible text in print: 8pt at final print size.
- Avoid very thin strokes (under 0.5pt) on small text — they may not reproduce cleanly.

## Final Check Before Uploading

- View your file at 100% zoom and check for blur or pixelation.
- Confirm the background is transparent if needed.
- Verify the file is in RGB mode.
- Confirm the canvas dimensions match or exceed the recommended print size at 300 DPI.

For a detailed reference on print areas for specific products, see **Design Resolution & Print Area Guide**.
