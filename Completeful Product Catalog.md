# Completeful Product Catalog

Reference list of the live, published catalog for content planning. Pulled directly from the Completeful production database, filtered to the same query the public catalog page uses (`is_active = true AND status = 'published'`).

## Scope and counts
- 123 distinct products (by name), 634 active published SKUs once colors and sizes are counted.
- 4 live categories: accessories (90), drinkware (28), home (3), apparel (2).
- The public site markets "900+ products." That figure counts every color and size variant plus draft and seasonal items. This note lists the distinct sellable products, which is the useful unit for content ideas.
- Print and personalization methods in use: laser engraving, laser etching, UV printing, sublimation, and embroidery. That spread maps directly to the owned equipment fleet (6 fiber lasers, 28 engraving machines, 16 embroidery machines, UV printers).
- Most products are personalized at a unit price under $15, which supports the no-minimums and margin-lever messaging.

> Data note: a handful of records still carry placeholder descriptions ("fulfilled by Completeful") or draft pricing such as $0.00. Those are flagged inline. Refresh this note by re-querying the database when the catalog changes.

How to read each line: **Product** ($price, method): short note. Price is the variant range. Bestsellers are tagged [Bestseller].

## Using this catalog for content ideas
- Map each product cluster to a seller niche, then to a content pillar. Example: Knives and EDC plus Golf plus Barware feed the product-showcase pillar with high-margin personalized-gift angles.
- Personalization method is a built-in behind-the-scenes hook. Every laser, UV, and embroidery product is a demo waiting to be filmed, and each ties back to the owned-equipment proof.
- Price points under $15 reinforce the no-minimums and margin-lever messages: show the blank cost next to the personalized sell price.
- Watch the gaps: apparel and home are thin. If a campaign targets apparel sellers, note the limited selection before promising range.
- Cleanup candidates for the team: products with SKU-style names (PGL-128, PGL-67, PGL-91) and placeholder "fulfilled by Completeful" descriptions read poorly in content. Flag for a catalog copy pass.
- Refresh: re-run the published-and-active query against the Completeful database to update counts and catch new drops.
